# 보상 · 수집 설계 (v0.2)

## 가설
- H12 ❓ 한국 블박 제보 문화(블박 신고 → 범칙금/과태료, 한문철TV)를 그대로 게임 보상으로 옮기면, 별도 설명 없이도 "퇴치 = 보상"이 직관적으로 이해된다. 훈장처럼 과하지 않고 웃기다.
- H13 ❓ 보상은 3겹으로 쌓는다. ① 수집(빌런 도감 = 블박 제보 앨범) ② 재화(포상금 → 업그레이드) ③ 사회적 인정(참교육 채널 구독자·댓글·플레이버튼).

## 1. 블박 제보 카드 (수집 = 도감)
- 빌런을 퇴치하면 킬 순간의 **블랙박스 캡처**(실제 게임 화면)로 카드가 한 장 만들어진다.
  - 오버레이: `● REC 2026.10.13 14:32:07`, 속도, 차선
- 카드 내용: 빌런 이름, 위반 조항(도로교통법), **범칙금/과태료 금액**, ★1~3(속시원함 지수 기준)
- 도감: 스테이지마다 카드 1장. 아직 못 잡은 빌런은 실루엣과 "제보 대기 중"으로 표시. 같은 빌런을 다시 잡으면 최고 별만 갱신한다.
- 다음 단계 아이디어: 희귀 변종(황금 번호판, 무지개 SUV), 챕터 완성 보너스

## 2. 포상금 (재화)
- "범칙금은 빌런이, 포상금은 내가." 퇴치하면 범칙금 금액에 ★ 배율(×1 / ×1.5 / ×2)을 곱한 만큼 적립하고, 갓길 얌체 신고 보너스를 더한다.
- 사용처(v0.3 후보):
  - 차량 스킨: 경차 → 견인차 → 암행순찰차 st.
  - 무기: 압정 → 마름쇠 → 물풍선 → 견인 와이어
  - 경적 소리: 트로트 경적, "대~한민국" 경적
  - 비상등 색

## 3. 참교육 채널 (사회적 인정)
- 클리어할 때마다 블박 영상이 자동으로 업로드된다.
  - 조회수와 구독자 증가량은 속시원함·해방 차량 수에 비례한다.
  - 결과 화면에 가짜 댓글 2~3개를 띄운다. 예: "사이다 ㅋㅋㅋ", "이분 국가유공자 지정해라", "10년 묵은 체증 내려감"
- 구독자 마일스톤: 1천 → 1만 → **10만 실버 버튼** → **100만 골드 버튼**(패러디 "참교육 플레이버튼"). 훈장 대신 쓴다.
