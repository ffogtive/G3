## 가설
- ✅(조건부) 비판을 반영하면 100종 모두 개연성(정체 인과 한 줄), 재미(엔진 시그니처 100개 모두 다름), 톤(PG, 구조형은 경적만), 구현 가능성(새 메시 0, 기존 차종·투사체 재사용)을 갖춘다.
- ❓ 단, 보스 페이즈·lane·count·경적 전용·포상금 분리는 stagegen 연동 패치 전까지 엔진이 무시한다. config.js 손제작 id 충돌(E1)도 패치 전까지 남는다.
- ❌ 원천 리서치 풀 링크는 이 단계에 없었고 웹 검색 한도도 소진되어, 금액은 기억으로 정정했다. 미검증은 (추정)·(확인 필요)·(게임값)으로 표기했고 출처는 법령 원문 링크다.

> 데이터 원본: `game/js/data/villain_catalog.json` (연동 패치 뒤 `node tools/catalog2js.mjs`로 `villain_catalog.js`를 생성해야 게임이 이 카탈로그를 쓴다. 이번 작업에서는 실행하지 않았다). 그래픽은 사용자 확정대로 현행 복셀 스타일을 유지한다.
> 표기: `템플릿×N` = 차량 N대, `50% →` = 보스 HP 50%에서 페이즈 전환. 금액은 카드에 표시할 법정 금액(형사 카드는 법정 상한), 포상금(payout_krw)은 별도 게임값.

### 엔진 연동 체크리스트 (이 카탈로그를 켜기 전에)

이 작업은 새 파일 2개만 만들었다. 아래는 다음 작업에서 기존 파일을 고칠 목록이다.

1. **E1 손제작 id 충돌**: `config.js` STAGES id 1~5가 카탈로그 1~5를 덮어쓴다. id를 2→11, 3→4, 4→9, 5→50으로 바꾸거나, `buildStages`가 `handmade_id`로 매칭하게 한다. 5번 제목의 "(최종보스)", 이름 "전설의 경운기 할배"(`config.js`, `docs/GAME_DESIGN.md`), 대사 "허허, 젊은 것들이 급하긴"·"빵빵거리지 마라 귀 아프다"·"옛날엔 다 이렇게 다녔어"도 함께 정리한다. tractor 모델은 그대로 둔다.
2. **E2·E3 보스**: `movement`는 P1 템플릿 하나만 쓴다. `phases[]`(hp, movement, lane, count, attacks)를 읽고, `boss`(HP×1.6)·`elite`(HP×1.3, 제안) 플래그를 `id%10` 대신 쓴다.
3. **E5 공격 다양성**: merge_blocker는 stopped:false(서행)로 두어 lunge·swerve가 지워지지 않게 한다. summon은 보스·엘리트 전용으로 구현한다.
4. **E6·E8 lane·count**: 모든 템플릿이 `lane`(시작 차로, 0=1차로, 0.5 단위는 걸침)과 `count`(차량 수)를 따른다. 정지형도 count 1이면 "(상대)" 차를 만들지 않는다.
5. **E7 차종**: `vehicle`은 전부 기존 kind다. 정규식과 강제 덮어쓰기를 건너뛴다.
6. **투사체**: `throw_item`을 `throwItemFor`보다 우선한다. box·tire·cone은 PROJ 별칭을 등록한다.
7. **구조·안전 스테이지**: 빈 `attacks`는 기본 공격으로 채우지 않는다. `weapons:["honk"]`면 압정·미사일 버튼을 숨긴다.
8. **E10 보상**: `rewards.js`는 `payout_krw`로 포상금을 계산하고, 카드에는 `fine_krw`와 `violation`을 표시한다. `fine_krw` 0(계도)이 `|| 30000`에 먹히지 않게 `??`를 쓴다.
9. **난이도**: `difficulty`(정수, 1~10)는 그대로 두고 `difficulty_f`(톱니형 소수)가 있으면 그 값을 쓴다. 공식: B(c)=1.5+0.85c, 정규 k번째 = B(c−1)−0.5+0.1(k−1), 보스 = B(c), 최종보스 10. #73은 보너스 3.
10. **(소) 국도 라벨**: road가 "국도 N호선"이면 노선 배지를 국도로 표시한다(지금은 임의 고속도로명이 붙는다).

### 검증 결과

- 엔진 시그니처(movement·lane·count·vehicle·공격 매핑·투사체) 100개가 모두 서로 다르다. 챕터 안에서 movement+vehicle 조합도 겹치지 않는다. 패치 전 현재 stagegen 출력(차종·차로·공격·투사체·하늘)으로 비교해도 중복 0이다.
