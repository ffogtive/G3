# 주차 빌런 퇴치 — 휴게소 미니 코너 (스펙 v0.1)

## 0. 초안 대비 고친 점 (적대적 검토)
- **법 ❌ #10 "제64조 ₩40,000":** 근거 표에 없다. 출입구 막기는 2026-08-28 시행 주차장법(노외·부설주차장, 최대 500만원)으로 바꾼다. 휴게소에 적용되는지는 ❓라서 상가·마트 장소(2차)로 옮긴다. 연출도 법 절차를 따른다: 관리자 이동 권고 → 불응 → 지자체 견인(즉시 견인 아님). "레커로 직접 즉시 견인"은 뺀다.
- **법 ❌ 추가 후보 "소방차 전용구역 캠핑카":** 대상이 100세대 이상 아파트와 3층 이상 기숙사뿐이라 휴게소에는 없다.
- **법 고침:** 충전구역 조문은 제11조의2가 아니라 제16조·시행령 제18조의8이다. 급속 1시간 초과 10만원은 확인됐으므로 (추정)을 지운다. #1 "처벌 조항 없음"도 확인됐다 ✅. "차로 밀다가 형사 사건" 주장은 출처가 없어 지운다.
- **법 고침:** 칸 규격 중 근거가 있는 것은 일반형 폭 2.5m(2019-03 이후 신축)와 확장형 2.6×5.2m뿐이다. 경형·장애인 칸·통로 폭은 (추정)이다. `cards.json`의 fine 케이스는 금액 라벨이 "범칙금"으로 고정돼 있어서, 과태료 카드용 라벨 오버라이드가 필요하다.
- **경제 ❌:** 본선 규칙(포상금 = 범칙금 × ★)을 그대로 쓰면 주차방해 50만·출입구 500만원이 본선(4만원대)을 압도한다. 미니 코너는 정액 포상금으로 하고, 카드의 금액은 표시용으로만 쓴다.
- **윤리 ❌:** #2 전광판에 차종·번호를 띄우는 공개 망신 → 관리요원 계도장 + 차주 호출로 바꾼다. #1 짐 변종 "요원이 가져감" → 주인이 직접 끌고 간다(개인 콘만 요원이 회수).
- **윤리 ❌ #8 "앞코 선점":** 본선 빌런(T1 들이밀기)과 똑같은 행동이다. 후진등 텔을 읽고 기다리는 방식으로 바꾸고, 하이에나는 스스로 갇히게 한다.
- **안전 ❌:** 진행 방향 1.5m 박스로는 후진·회전 때 차체가 쓸고 가는 영역을 다 덮지 못한다 → swept envelope로 바꾼다. "충돌 판정 없음"만 두면 사람이 차를 통과해 보인다 → 보행자도 envelope 앞에서 기다리게 한다.
- **템포·구조:** 표지판을 RELEASE에 띄우면 해방 연출을 가린다 → CRUISE에 표지판, RESULT에 버튼. RoadGraph(N6)에는 `rest_area` 구간 타입이 없다 → 씬 전환으로 처리하고 도로는 건드리지 않는다.
- **기타:** '통감자 분노 +1칸'은 상점 '졸음쉼터 커피'와 겹친다 → 분노 획득 +15%로 바꾼다. 눈은 라인 텔(#2·#3)을 가린다 → 둘과 같이 나오지 않게 한다. 90초 자동 주차에 ★1을 주면 SHOP 규칙(★1 = 해결)과 충돌한다 → ★0 + 간식 1개. 10종을 한 번에 만들지 않는다 → 스파이크(#1·#2) → MVP 5종 → 2차 5종.

## 1. 위치·리듬
- **빈도:** 챕터당 2회, X-4와 X-8 뒤다 ❓("짬짬이" = 4~5분마다). 첫 방문은 1-4 뒤 40초 튜토리얼이다.
- **진입:** CRUISE에 녹색 표지판 "○○휴게소 2km"가 보이고, RESULT에 [들르기][통과]가 뜬다. 통과해도 진행에서 잃는 것은 없고 간식만 못 받는다. 진출 램프 컷 2초 후 씬을 바꾼다.
- **추가 진입:** 보스에게 2번 연속 지면 실패 카드에 "휴게소 들렀다 가기(간식 버프)" 칩을 띄운다. 스테이지당 1회이고 모달은 아니다.
- **길이:** 45~75초다. 탐색 10~20초, 빌런 15~25초, 정렬 10~20초, 카드 5초. 연출은 6초 이하이고 탭하면 넘어간다.
- **실패 없음:** 범퍼 HP·분노는 쓰지 않는다. 60초가 넘으면 관리요원이 "제가 안내할게요" 하며 어시스트를 한 단계 올린다. 90초가 되면 요원이 빌런을 처리하고 자동 주차한다. ★0 + 간식 1개이고 재도전 화면은 없다.
- **템포 보호:** 같은 빌런은 연달아 나오지 않는다. BGM은 로파이 휴게소 곡이다. 출발하면 간식 아이콘이 HUD에 붙고 바로 다음 판이다.

## 2. 조작 (폰, 엄지 하나)
| 단계 | 입력 | 이유 |
|---|---|---|
| 이동 | 빈칸 P 마커나 확인 링을 **탭**하면 차폭 고스트로 경로(A*)가 미리 보인다. 화면 아무 데나 **누르고 있으면** 시속 8km 이하로 따라가고, 떼면 바로 선다(dead-man) | 손가락이 차를 가리지 않는다. 경로는 엔진이 회전반경 안에서 계산하므로 "그린 대로 안 감"이 없다. 오토파일럿과 같은 코드다 |
| 정렬(칸 3m 앞에서 자동 전환) | 우하단 **정렬 패드**. 좌우 드래그 = 조향(손을 떼도 유지), [앞]·[뒤] 홀드 = 시속 3km 이하. 후방카메라 궤적선 패러디, 햅틱 주차센서 틱(최대 8Hz) | "딱 맞췄다" 손맛은 이 단계에만 둔다. 엄지 하나로 '돌리고 → 누르기'를 번갈아 하고, 두 손가락 동시 조작도 된다. 왼손 모드는 좌우 반전 |
| 대응 | 확인 링에서 **확인 게이지**(N3)가 차면 그 빌런의 공식 수단 버튼 1개가 뜬다. 경적은 따로 있다(R2 피로) | 판단은 "어디서 확인하나 + 함정인가"에 있다. 암기 퀴즈는 없다 |
- **카메라:** 3/4 탑다운, 피치 55°. 이동 중에는 줌아웃, 정렬 중에는 줌인하고 칸을 화면 위쪽에 고정한다. **다이얼 방향 = 화면에서 궤적선이 휘는 방향**이다(후진 때는 내부 조향 부호를 뒤집음). 후진할 때 좌우가 헷갈리지 않는다.
- **어시스트 3단계:** 가이드(칸 중앙으로 끌어당김, 텔 강조) / 기본(궤적선 + 센서) / 수동(둘 다 없음, 포상금 ×1.5).
- **기각:** 핸들·페달 상시 조작(두 엄지 동시 정밀 = 이 장르 최대의 짜증), 손가락 경로 그리기(가림, 보정 불일치), 탭 한 번 자동 주차(손맛 0).

## 3. 공통 루프
1. **진입:** 전광판에 "잔여 3면", 빈칸에 초록 P.
2. **막힘:** 빌런이 나오고 N5 아이콘과 말풍선이 뜬다. 처음 보는 빌런만 한 번 설명한다(N3).
3. **확인:** 빌런마다 확인 위치가 다르다(앞유리 정면 2m / 바퀴 옆 / 앞·뒤 2컷 등). 함정(합법 차)은 게이지가 차면 "합법 ✓"로 끝난다. 게이지가 덜 찬 채 신고하면 오인 신고다(N3 페널티 + 눈총).
4. **참교육 연출(6초 이하):** 관리요원, 안내방송, 단속, 견인, 앱 신고, 와이퍼에 끼우는 종이 계도장만 쓴다. 빌런은 다치지 않고 민망해지기만 한다.
5. **완벽 주차:** 정렬 → 시동 끔 → 사이드 '딸깍'(햅틱) → "주차 완벽!" 도장.
6. **마무리:** 카드와 간식을 고르고 본선으로 돌아간다. 2차부터 일부 판에는 출차 단계 빌런이 1명 더 있다.
- **콕(주차된 차 접촉):** 차가 서고 콕 1회로 센다. "연락처 메모를 남겼습니다" 토스트가 자동으로 뜬다(물피도주 방지 교육, 근거 표 참고). 파손은 없다.
- **사람에게 경적:** 효과는 없고 눈총 +1, "사람한테 빵은 좀…" 말풍선.

### 2차 5종 (MVP 판정 뒤)
- **콘센트 없는 충전러:** 일반차(흰 번호판 + 케이블 없음, 전기·수소차는 파란 번호판), 또는 급속 1시간 초과(커넥터 빠짐 + 초과 타이머). 함정은 케이블을 꽂고 진행 바가 도는 차다(흰 번호판 플러그인 하이브리드 포함, 추정). 앱 신고하면 차주가 우동 그릇을 들고 종종걸음으로 온다. 고지서 ₩100,000 ✅ (휴게소 적용 ❓).
- **통로 한가운데 망부석:** 비상등을 켜고 통로를 막은 채 나갈 차를 기다린다. 뒤에 5대 줄. 해법은 경적 짧게 1회다(R2: 2회째는 50%, 길게 누르면 오답). 기다리던 차는 트렁크만 정리하던 차(후진등 꺼짐)라 허탕 치고 한 바퀴 더 돈다. 뒤 5대가 비상등으로 감사한다(RELEASE 축소판). 계도장.
- **후진등 하이에나:** 나는 깜빡이를 켜고 후진등이 켜진 차(진짜 나가는 차)를 기다리는데, 반대편에서 무깜빡으로 머리부터 들이민다. 해법은 기다리기다(먼저 진입하거나 경적을 길게 누르면 "똑같은 사람 되기" 눈총). 하이에나는 나가는 차의 후진 경고음에 막혀 통로에 갇히고, 요원이 "먼저 기다린 차 순서입니다" 한다. 후진으로 빠져나가 '다음 휴게소 27km' 앞에서 한숨. 계도장.
- **경차칸 두 칸 SUV:** 경차칸 2칸을 차지하고 꽁무니가 통로로 1.2m 튀어나왔다. 거대한 자(V04 #4)로 "SUV 4.9m / 경차칸 3.6m(추정)". 요원이 "일반칸은 저쪽 끝이에요(300m)". 계도장 (경차칸 일반차 과태료 근거 없음 ❓).
- **출입구 알박기 (상가·마트 장소, 출차 단계):** 출입구에 세워 두고 연락을 안 받는다. 블박 → 관리실 신고 → 관리자 이동 권고 방송 → 불응 → 지자체 견인(차고에 레커가 있으면 내 레커가 위탁 견인으로 출동). 고지서 "과태료 최대 ₩5,000,000" ✅ (1차 금액은 100만/200만 보도가 엇갈림 ❓).
- **후보 풀:** 차박 장기 점유(계도), 트레일러로 세 칸, 대형칸을 차지한 승용차. 핑크(임산부)·가족배려 칸은 강제력 근거가 없어서 합법 함정으로만 쓴다.

## 5. 별·보상
- **별(미리 보여 줌):** ★1 빌런 해결 / ★2 완벽 주차(중앙 ±15cm, 각도 ±3°, 전진·후진 전환 2회 이하 ❓ 기기에서 조정) / ★3 콕 0 + 눈총 0 + 오인 신고 0.
- **포상금:** 정액 ₩10,000 × ★ 배율(×1 / ×1.5 / ×2). 수동 어시스트는 ×1.5를 더 곱한다. 카드 금액은 "빌런이 내는 돈"으로 표시만 한다(본선 경제 보호).
- **간식(다음 1판만):** ★ 수만큼 선택지가 나온다(최소 1). 호두과자 범퍼 +1칸 / 통감자 분노 획득 +15% / 아메리카노 경적 쿨 −20% / 소떡소떡 포상금 +10%.
- **수집·차고:** 블박 카드(REWARDS)에 휴게소 도장판(장소 × 빌런 도감)을 더한다. 차종에 따라 치수와 회전반경만 바뀐다(경차 쉬움, 1톤 포터 어려움). 상점 후보로 '어라운드뷰'(어시스트 +1, 감점 없음).

## 6. 안전·윤리 불변식 (입력으로 끌 수 없음)
- **보행자 정지:** 현재 진행 방향(후진 포함)으로 차체가 max(1.5m, 속도×0.5초+0.5m) 동안 쓸고 갈 영역과 좌우 0.4m 안에 사람이 있으면 sim이 강제로 세운다. 설 때 "보행자 우선" 칩과 약한 햅틱을 줘서 버그처럼 느껴지지 않게 한다.
- **보행자 대기:** 보행자는 차의 envelope 안으로 걸어 들어오지 않고 기다린다(클리핑 방지). 차와 사람의 충돌 이벤트 자체가 없다.
- **T0 속성 테스트:** 시드 1000개 × 무작위 입력 퍼징에서 차체와 사람의 최소 거리 0.3m 이상, 접촉 0.
- **해법 제한:** 공식·사회적 수단만 쓴다. 차량 접촉, 밀기, 파손, 키 긁기, 강력 접착 스티커는 없다(접착 스티커는 재물손괴 판결 ✅). 계도장은 와이퍼에 끼우는 종이다.
- **노출 제한:** 빌런은 다치지 않는다. 번호판·얼굴을 화면에 공개 송출하지 않는다(안내방송의 가상 번호까지만). 장애인구역 연출에서 웃음 대상은 위반자뿐이다.
